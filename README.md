## Mô tả bài thực hành

Kho lưu trữ này được tạo nhằm thực hành các thao tác quản lý phiên bản mã nguồn
bằng Git và GitHub, bao gồm:

1. Khởi tạo local repository và kết nối với remote repository trên GitHub.
2. Thực hiện commit cơ bản với `git add` và `git commit`.
3. Tạo và làm việc trên nhánh (branch) riêng: `feature/them-giao-dien`.
4. Gộp nhánh (merge) trở lại nhánh chính `main` và đẩy lên GitHub.

## Cấu trúc thư mục

```
ThucHanhGit_1822040474/
├── README.md     — Thông tin sinh viên và mô tả bài làm
├── index.html    — Trang web cơ bản
└── style.css     — Định dạng giao diện (thêm ở nhánh feature/them-giao-dien)
```

## Các nhánh

- `main` — nhánh chính, chứa phiên bản hoàn chỉnh sau khi merge.
- `feature/them-giao-dien` — nhánh phụ, dùng để phát triển phần giao diện CSS.
